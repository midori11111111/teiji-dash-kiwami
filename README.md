# 定時ダッシュ極

> 定時になった。帰るだけなのに、命がけ。

## 🎮 [今すぐプレイ](https://midori11111111.github.io/teiji-dash-kiwami/)

部長の「ちょっといい？」をかわしながら、タイムカード・上着・帰る勇気を回収して60秒以内に退勤するオフィス脱出ステルスゲームです。

### 操作

- PC：WASD または矢印キー
- スマートフォン：画面下の方向ボタン

3つの帰宅セットを集め、右下のエレベーターへ到達すれば退勤成功です。部長の赤い索敵範囲に入り続けると、議事録担当にされます。

### ローカル起動

```bash
npm install
npm run dev
```

GitHub Pages版は `npm run build:pages` で `docs/` に生成されます。
